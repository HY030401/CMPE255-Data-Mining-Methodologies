# KDD — Credit Card Fraud

Dataset: `creditcard.csv`. See `data/README.md` for original download.

Run from repository root:

```bash
python 03_KDD/src/run.py --data /path/to/creditcard.csv --out 03_KDD/artifacts
```

Outputs: `artifacts/metrics.json`, trained model, and for SEMMA customer segments. See `reports/methodology_report.md` for actual measured metrics, stages and limitations.
