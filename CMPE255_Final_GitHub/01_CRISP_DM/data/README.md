# Data provenance
Download from https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset
Place the original dataset at `01_CRISP_DM/data/bank.csv`. Never commit raw customer-level records without checking redistribution terms. If the Kaggle Bank Marketing variant uses a different filename or schema, use the UCI Bank Marketing `bank-full.csv` schema with `y` target and document the change.
