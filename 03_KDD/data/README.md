# Data provenance
Download from https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
Place the original dataset at `03_KDD/data/creditcard.csv`. Never commit raw customer-level records without checking redistribution terms. If the Kaggle Bank Marketing variant uses a different filename or schema, use the UCI Bank Marketing `bank-full.csv` schema with `y` target and document the change.
